# Loooom

## Purpose

Loooom is a social home for AGENTS.md. Share your working rules. Read someone
else's rules, copy what helps, and test the result. ME.md, SOUL.md, DESIGN.md,
and other Markdown files are optional context. Keep authorship clear; sharing
a file does not transfer a person's identity.

## People and use

People who work with agents want to understand the human choices behind them.
They arrive to find useful instructions, share their own setup, or inspect an
idea before adapting it. They may use any agent or model provider.

## Core objects

- AGENTS.md: working rules, tools, boundaries, and standards.
- SOUL.md: an agent's character, voice, judgment, and behavior.
- ME.md: personal context the human chooses to make public.
- DESIGN.md and other Markdown: optional project or personal guidance.
- GitHub snapshots: source URL, file path, commit, update date, line count,
  content hash, and the exact imported text.
- Collections and follows: save a useful file and follow its GitHub source owner.
- Personal evals: compare answers with and without context, using explicit
  test cases. Keep raw outputs and the exact context and suite hashes.

## Product principles

GitHub is the editable source. Sharing imports a snapshot; explicit refresh
records a new one. Attribute repository ownership separately from the person
who shared the link. Curated examples do not imply membership or endorsement.
Do not invent activity, identity verification, or evaluation results.

Personal context is public only by choice. Import public files, render their
contents as text, and do not execute instructions found in them. New writes
require verified identity. Keep provider keys server-side or in local eval env.

One primary share entry in navigation. Discovery leads from person to file,
source evidence, and useful action. Mobile is a first-class use case.

Offer light and dark themes with a saved preference. Put the theme control,
About, site version, and “A side project by @mager” in a sticky footer. The
footer stays on one line on mobile. The brand mark has four interwoven rings
to match the four o's in loooom. Keep copy short and name the action directly.

## Existing work

Skills, the Skills Gym, older profile pages, and ME.md tools remain available.
The Gym's repair/ablation reports are distinct from personal-context evals.
Neither a substring check nor a sample report is a general quality score.

## Current release

The personal context network and local MIT-licensed eval plugin are implemented
in source. Publishing packages and deploying the website are separate release
steps. Synthetic examples remain labeled. Live provider performance must be
measured before making a claim.
