# Loooom — Volume 1

> Skills for the 99% who don't code.

The wedge: every skill directory out there is dev tooling. Loooom Volume 1 is a
**curated craft drop** of non-technical skills — life, creativity, communication —
authored to a quality bar nobody else hits, presented beautifully, and runnable
**in the browser** (no Claude Code, no CLI, no install).

This is the impeccable.design model: supply = us, win on taste, earn the right to
open it up later.

## House style

- **One-word names.** Like impeccable's `animate` / `polish` / `distill`. Turns a
  grab-bag into a *collection*.
- **Real expertise, real voice.** No generic prompt slop. Every skill ships with
  method, concrete examples, and a point of view — "context is first-class."
- **Try-it-in-browser is the front door.** Every skill page has a live chat that
  runs the skill (Claude API, skill behavior as system prompt). "Add to Claude
  Code" is the side door for devs.
