## Design Context

### Users
People using coding agents come to Loooom to inspect real AGENTS.md files, copy useful instructions, save files, and follow their GitHub owners. Reading and evaluating the source is the primary job; provenance supports trust.

### Brand Personality
Minimal, utilitarian, direct. Make the interface feel capable and easy to scan. The user explicitly prefers this direction and wants less introductory text and wasted space.

### Aesthetic Direction
Retain Night Press: Outfit for the interface, Space Mono for source, ink and paper themes, lime for primary actions, and lavender for supporting links. Use compact workspace layouts, restrained borders, and clear typography. Both themes deserve equal care. Avoid large introductory heroes on reading pages, repeated attribution, promotional filler, and decorative cards. See DESIGN.md for shared tokens.

### Design Principles
1. Put the file first. Source text should begin in the first viewport; metadata and secondary actions must not push it down.
2. Give each action a clear rank. Copy is primary in the reader; save and GitHub are secondary; follow and refresh belong with source details.
3. Use density with readable type. Keep controls and metadata compact while giving source text comfortable size, contrast, and line spacing.
4. Make color functional. Lime identifies actions and headings; lavender identifies supporting links. Keep prose in a neutral ink color.
5. Preserve trust and access. Show exact source text, distinguish owner from sharer, keep provenance accessible, support keyboard focus and reduced motion, and verify both themes down to 320px.
